THE LEARNING PATH
How should I use this handbook?Start in order if you are new: build a minimal loop, understand state and recovery, then connect a full application. Backend developers can begin with LangGraph in chapter 11 and revisit module 2 for tools and context. Each chapter follows Why → How → Example → Code → Experiment → Validation. Excerpts and pseudocode are labeled; pin dependencies and implement the adapters for your own project.
